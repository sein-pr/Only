🛍️ Shopy

Your Premium E-commerce Shopping Destination

📋 Overview

Shopy (formerly "Only") is a comprehensive e-commerce web application developed using the Flask framework. This project aims to provide a seamless shopping experience with integrated payment processing capabilities, advanced user management, and a robust seller dashboard system.

🎯 Project Goal: Create a modern, scalable e-commerce platform that supports both buyers and sellers with advanced features like real-time cart management, secure payment processing, and comprehensive analytics.

✨ Features

🛒 Product Catalog
Browse and search through a wide range of products with advanced filtering options.
🔐 User Authentication
Secure login and registration system with role-based access control.
🛍️ Shopping Cart
Advanced cart management with save-for-later functionality and guest support.
💳 Payment Gateway
Integrated with Stripe for secure payment processing with tax and shipping calculations.
📦 Order Management
Complete order tracking system with status updates and order history.
📱 Responsive Design
Mobile-first design ensuring smooth experience across all devices.
👥 Multi-Role System
Separate interfaces for buyers and sellers with specialized dashboards.
📊 Analytics Dashboard
Comprehensive sales analytics and product view tracking for sellers.

🛠️ Technology Stack

Python 3.11 Flask 2.3.3 PostgreSQL SQLAlchemy Bootstrap 5.3 Stripe API Docker Nginx

Backend Technologies

  • Python: The core programming language used for backend development
  • Flask: Lightweight web framework that powers the application
  • SQLAlchemy: Object-Relational Mapping (ORM) for database operations
  • PostgreSQL: Robust relational database for data persistence

Frontend Technologies

  • HTML5/CSS3: Modern markup and styling
  • Bootstrap 5.3: Responsive CSS framework
  • JavaScript: Interactive user interface components
  • Font Awesome: Icon library for enhanced UI

Third-Party Services

  • Stripe: Payment processing and secure transactions
  • Flask-Mail: Email notifications and communications
  • Docker: Containerization for easy deployment

🚀 Installation

To set up the project locally, follow these step-by-step instructions:

1Clone the Repository

git clone https://github.com/sein-pr/Only.git

2Navigate to the Project Directory

cd Only

3Install Dependencies

Ensure you have Python 3.11 and pip installed, then run:

pip install -r requirements.txt

4Set Up Environment Variables

Create a .env file in the project root with the following variables:

SECRET_KEY=your-secret-key-here
DATABASE_URL=postgresql://username:password@localhost:5432/only_db
STRIPE_SECRET_KEY=your-stripe-secret-key
STRIPE_PUBLISHABLE_KEY=your-stripe-publishable-key
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password

5Set Up Database

Create a PostgreSQL database and run the application to initialize tables:

python app.py

6Access the Application

Open your browser and go to http://127.0.0.1:5000/

💡 Pro Tip: For production deployment, use Docker Compose with the provided docker-compose.yml file for a complete setup including PostgreSQL, Redis, and Nginx.

🐳 Docker Deployment

For easy deployment using Docker:

# Build and start all services
docker-compose up -d

# View logs
docker-compose logs -f

# Stop services
docker-compose down
