📋 API Overview

The Shopy E-commerce API provides a comprehensive set of REST endpoints for building e-commerce applications. Our API supports both buyer and seller functionalities, including product management, shopping cart operations, order processing, payment handling, and analytics.

🛒 Shopping Cart
Complete cart management with guest and authenticated user support
👨‍💼 Seller Dashboard
Analytics, order management, and product control for sellers
📊 Analytics
Sales trends, product views, and performance metrics
💳 Payment Processing
Secure Stripe integration for payment handling

🔐 Authentication

Most API endpoints require user authentication. Authentication is handled through Flask sessions. Some endpoints are accessible to guest users (like product browsing), while others require login.

⚠️ Authentication Required: Endpoints marked with AUTH require user authentication.

Session-based Authentication

The API uses Flask session management for authentication:

  • Login: POST /login with email and password
  • Session Storage: User ID, username, and role stored in session
  • Role-based Access: Different permissions for buyers and sellers

🛒 Cart Management Endpoints

Get Cart Items

GET /api/cart-items
Retrieve all items in the current user's cart (works for both guests and authenticated users)
Response Example:
JSON Response
{ "items": [ { "id": 1, "name": "Premium Wireless Headphones", "price": 29.99, "quantity": 2, "total": 59.98, "image_url": "/static/uploads/headphones.jpg", "stock_quantity": 10 } ], "total": 59.98, "count": 1, "shipping": 5.99, "tax": 4.80 }

Get Cart Count

GET /api/cart-count
Get the total number of items in the cart
Response Example:
JSON Response
{ "count": 3 }

Add to Cart

POST /api/add-to-cart/{product_id}
Add a product to the cart with quantity validation and stock checking
Request Body:
JSON Request
{ "quantity": 2 }
Success Response:
JSON Response
{ "success": true, "message": "Premium Wireless Headphones added to cart!", "cart_count": 3 }
Error Response:
JSON Error Response
{ "success": false, "message": "Not enough stock available" }

Update Cart Item

POST /api/update-cart-item/{item_id}
Update the quantity of a cart item with stock validation
Request Body:
JSON Request
{ "quantity": 3 }

Remove Cart Item

DELETE /api/remove-cart-item/{item_id}
Remove an item from the cart completely

⚠️ Error Handling

All API endpoints return consistent error responses with appropriate HTTP status codes.

Error Response Format

JSON Error Response
{ "success": false, "message": "Error description", "error": "Detailed error information" }

Common HTTP Status Codes

200 Success
Request completed successfully
400 Bad Request
Invalid request data or parameters
401 Unauthorized
Authentication required
403 Forbidden
Insufficient permissions
404 Not Found
Resource not found
500 Internal Server Error
Server-side error occurred

🚦 Rate Limiting

📊 Current Status: API requests are currently not rate-limited, but we recommend implementing reasonable request intervals to ensure optimal performance for all users.
💡 Best Practice: Implement client-side throttling for high-frequency operations like cart updates and product view tracking to maintain good user experience.
